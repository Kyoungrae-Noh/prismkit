## 공식 자료 조사

- [검색광고 API 공식 FAQ](https://github.com/naver/searchad-apidoc/wiki/FAQ): 호출 총량 제한은 없다고 안내하지만, 광고주별 속도 제한이 있으며 키워드 API는 Customer ID와 클라이언트 IP가 기준에 포함된다. 속도는 서비스 부하에 따라 달라져 고정 RPS를 제시하지 않는다. 초과 시 HTTP 429가 발생할 수 있다. 이는 무제한 동시 호출 또는 무료라는 의미가 아니다.
- [키워드 도구 429 공식 안내](https://naver.github.io/searchad-apidoc/notice/2020/12/18/notice/): 키워드 도구에는 다른 기능보다 엄격한 속도 제한이 적용된다. 429 발생 시 충분히 기다리고 반복 호출을 피하도록 안내한다. 이 안내는 2020년 공지이며 현재 계정의 허용 속도를 실측한 것은 아니다.
- [광고주센터 API 신청 도움말](https://ads.naver.com/help/faq/991): 서비스 신청과 인증키 발급 절차는 확인했으나 키워드 조회 호출의 무료 여부·단가를 확정할 내용은 확인하지 못했다.
- FAQ가 연결하는 [기존 API 약관 경로](https://saedu.naver.com/adguide/policy/api.nhn)는 웹 도구로 접근하지 못했다. 일반 광고 운영정책에서도 키워드 도구 호출의 과금 조건을 확정하지 못했다.

제3자 안내의 무료 주장을 공식 과금 근거로 대체하지 않았다. API HUB의 요금 정책을 검색광고에 적용하지 않았다. 공개 문서 열람 외에 인증 API 호출은 하지 않았다.
