# Phase 2D 경쟁·발행 판단 — 수동 근거 기반 실험 규칙

확인일: 2026-10-19. 현재 구현은 `src/domain/publishing.ts`다. 아래 규칙은 실제 노출 성과로 검증되지 않았다. **종합 점수, 가중 합산, 노출 확률, 방문자 수, 블로그 지수, 도메인 권위는 생성하지 않는다.** 이 문서 후반의 Phase 1 가중치 제안은 과거 설계 기록이며 실행하지 않는다.

## 경쟁 근거와 상태

사용자가 직접 네이버 검색을 열고 검색 URL·확인 날짜, 블로그 노출·위치, 공식 기관/대형 매체 점유, 정보형/상업형 환경을 입력한다. 최소 1개 경쟁 게시물의 제목·URL·발행일·요약·특징과 아래 9개 판단을 확인해야 진입 여부를 평가한다.

- 최신성, 제목의 의도 일치, 정보 구체성, 공식 자료 활용, 실제 문제 해결 수준
- 의도 충족의 빈틈, 최신 공식 자료를 통한 차별화, 롱테일 질문, 더 명확한 해결 방법

확인하지 않은 항목은 `확인 필요`다. 오래된 발행일만으로 낮은 품질을 단정하지 않으며 최신성은 사람이 평가한다. 검색 확인 후 30일이 지나면 환경 재확인을 요구한다(실험 임계값). 캡처는 근거 첨부일 뿐 판독하지 않는다. 검색 결과 수와 검색광고 경쟁도는 경쟁 상태 계산에 사용하지 않는다.

평가 우선순위:

1. 사용자가 명시적으로 제외 근거를 입력하면 **발행 제외**.
2. 필수 관측이 없거나 오래되거나 블로그 노출/위치 입력이 모순되면 **데이터 부족**과 미확인 목록.
3. 공식/대형 점유와 최신성·의도 일치·구체성·문제 해결이 모두 확인되면 **경쟁 강함**. 롱테일 질문 여지가 있으면 **롱테일 전환 추천**.
4. 블로그 노출, 의도 빈틈, 공식 자료 차별화, 더 명확한 해결 방법과 구체적인 보완 정보가 있으면 **진입 검토 가능**.
5. 나머지는 롱테일 여지가 있으면 **롱테일 전환 추천**, 그렇지 않으면 차별화 근거 부족에 따른 보수적인 **경쟁 강함**. 실제 순위 예측이 아님을 근거에 표시한다.

## 세 계정 이력과 중복

`nkr09134`, `nkr09135`, `nkr09136`만 관리한다. 초기 이력은 비어 있다. 예정·작성 중·발행 완료를 구분하고 완료에는 실제 날짜 및 해당 계정의 네이버 글 URL이 필요하다. 관련 글감과 Reviewman 페이지를 연결한다.

동일 원문 및 공백·기호 정규화 일치, 같은 주제와 유사 의도는 검토 경고를 표시한다. 주제는 사용자가 입력하거나 알려진 접미사를 제거해 추정한다. 사용방법·환불방법·사용처는 서로 다른 세부 의도로 처리한다. 같은 주제 또는 같은 Reviewman 페이지(UTM/fragment 제외)는 역할 차이를 확인할 참고 경고이며 자동 제외하지 않는다. 유사 의도 판정도 규칙 추정으로서 자동 삭제하지 않는다.

계정 추천에는 **세 계정 모두의 이력을 확인했다는 사용자 표시**가 필요하다. 동일/유사 의도 중복 계정은 제외하고, 같은 주제의 **발행 완료** 이력이 있는 계정 중 근거 개수가 가장 많은 한 계정을 제안한다. 동률·이력 없음·경쟁 근거 부족·DEMO면 확정하지 않는다. 계정 성능이나 권위를 추정한 추천이 아니다. 계획/작성 중 자료는 중복 검토에 포함하지만 주제 전문성의 발행 근거로 세지 않는다.

## 최종 발행 판단

| 상태           | 기준                                                                                                                                |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 발행 제외      | 사용자가 입력한 제외 근거                                                                                                           |
| 추가 조사 필요 | 경쟁 자료 부족/오래됨, DEMO, 불확실·충돌 의도, 수요 누락·`<10`·0, 주제 관련성 부족, 제외 후보, Reviewman 페이지 또는 계정 근거 부족 |
| 발행 보류      | 동일/유사 의도 중복 검토 필요 또는 경쟁 강함                                                                                        |
| 롱테일로 변경  | 경쟁 평가에서 롱테일 전환 권고                                                                                                      |
| 발행 검토 추천 | 진입 근거 + 실제/수동으로 확인한 양의 정확한 수요 + 명확한 의도·주제 관련성 + 연결 페이지 + 계정 주제 근거가 모두 있음              |

판정 순서는 제외 → 경쟁 자료 부족 → 중복 → 경쟁 강함 → 롱테일 → 나머지 추가 근거 → 검토 추천이다. 낮은 수요를 삭제하거나 임의 숫자로 바꾸지 않는다. Reviewman 페이지 입력은 연결 가능성을 나타내며 수익 검증으로 간주하지 않는다. 추천은 사용자 검토 단계로, 자동 발행이나 상위 노출 보장을 의미하지 않는다.

## 검증과 한계

단위 테스트는 누락·오래된 근거·중복·계정 동률·DEMO·검색량 경계·정상 검토 경로를 검증한다. 실제 사용자 글감과 발행 성과를 통한 규칙 검증은 별도 작업이다. 주제/의도 규칙은 의미를 완전히 이해하지 못하므로 구체적인 핵심 주제와 경쟁 특징을 직접 입력하고 경고를 검토한다.

### 경쟁 분석 평가 기준 — 실험용 제안

## 평가 요소와 잠정 가중치

모든 가중치·등급·임계값은 **실험용이며 성과 검증 전**이다. 0~4점 등급을 사용한다면 높은 점수는 발행에 유리한 근거를 뜻하도록 일관되게 정의한다. 미확인은 0점이 아니라 결측값이다.

| 요소                    | 실험 가중치 | 필요한 근거와 판단 방향                                                                   |
| ----------------------- | ----------- | ----------------------------------------------------------------------------------------- |
| 검색 수요               | 20%         | 같은 시점의 PC·모바일 검색수, `<10`/누락 구분, 계절성 확인; 많을수록 무조건 유리하지 않음 |
| 상위 콘텐츠 최신성      | 10%         | API 결과 발행일과 사용자가 확인한 업데이트 필요성; 오래된 글도 유효할 수 있음             |
| 상위 콘텐츠 품질        | 20%         | 허용된 범위의 사람이 읽은 평가: 정확성·직접 경험·출처·구체성; 제목/요약만으로 판단 금지   |
| 검색 의도 일치도        | 20%         | 정보·비교·구매 등 의도와 실제 원고의 해결 가능성                                          |
| 대형 사이트 점유        | 10%         | 조사 표본의 도메인 분포와 수동 확인; API 순위는 통합검색 점유율이 아님                    |
| 신규 블로그 진입 가능성 | 15%         | 유사 규모 사례와 독자적 경험·좁은 주제의 빈틈; 총 문서 수만으로 추정 금지                 |
| 기존 발행 글과 중복     | 5%          | 내 발행 이력, 유사 검색 의도, 기존 글 보완 가능성                                         |

향후 실험 합산식: `Σ(요소 등급 / 4 × 가중치)` (100점). 필수 근거가 없으면 합산·순위화를 생략한다. 검색광고 `compIdx`는 광고 경쟁 지표이므로 블로그 경쟁 점수로 넣지 않는다. `검색량 / total` 같은 단순 비율을 진입 난이도로 간주하지 않는다.

## 네 가지 결과

| 결과        | 제안 기준                                                                                               |
| ----------- | ------------------------------------------------------------------------------------------------------- |
| 발행 추천   | 수요·의도·상위 콘텐츠 표본·차별화·중복 검토의 근거가 모두 있고 사람이 최종 승인한 경우                  |
| 롱테일 전환 | 수요 또는 의도는 있으나 주제가 너무 넓거나 기존 강한 콘텐츠와 차별화가 부족하고 구체화 근거가 있는 경우 |
| 보류        | 인증/자료/품질/시점/의도 근거 부족, 출처 간 충돌, 또는 재확인이 필요한 경우                             |
| 발행 제외   | 중복 통합이 적절하거나 주제 부적합·해결 불가능 등의 명시적 근거가 있는 경우; 검색수 0만으로 제외 금지   |

현재 `assessResearch()`는 모든 수동 자료에 **보류**와 부족한 근거 설명을 반환한다. 나머지 결과는 타입과 문서에 정의했으나 자동 판정하지 않는다. 인증된 검색수만 확보해도 콘텐츠 품질 근거가 없으면 자동으로 발행 추천하지 않는다.

## 검증 계획

별도 Phase에서 사용자가 허용한 표본을 고정하고 평가자·조회일·API 정렬 방식·선정 기준을 기록한다. 두 명 이상의 평가 일치도와 발행 후 관측 기간별 성과를 검토한다. 기존 글/계절성/블로그 규모 효과를 분리하고, 학습 표본과 검증 표본을 나눈다. 임계값은 실제 결과를 본 뒤 결정하며 점수만으로 순위 상승·수익을 보장하지 않는다. 가중치 변경 시 버전과 근거를 남긴다.

## Phase 2C 후보 선정과의 구분

Phase 2C의 후보 상태는 위 미래 경쟁 점수와 별개다. `src/domain/candidates.ts`의 rules-v1은 실측/입력 검색량과 규칙 추정을 구분하고, 주제·의도·사용자 지정 Reviewman 연결어·유사 표현 중복을 검토한다. 실험 가중치나 경쟁 점수는 계산하지 않는다. 연령 가중치도 없다. [구체적 규칙과 한계](PHASE2C_REPORT.md)를 참고한다. 기존 수동 분석의 `assessResearch()` 보류 판정은 유지하며 후보 우선순위와 혼동하지 않는다.
