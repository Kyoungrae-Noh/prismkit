Cloudflare 인증이 유효하지 않아 **기존 Pages 프로젝트명, Git 자동 배포 연결, 원격 빌드 명령, 사용자 도메인 연결 세부 상태, 서버 환경변수·API 키의 존재 여부는 확인하지 못했습니다.** 공개 도메인의 Cloudflare 응답만으로 Pages 구성을 확정하지 않았습니다. 사용자 인증 파일을 갱신하거나 계정 설정을 수정하지 않았습니다.

`ops/legacy/`에는 기존 `_headers`, `ads.txt`, `robots.txt`, `sitemap.xml`, `site.webmanifest`를 원본 그대로 복사했습니다. `deployment-metadata.json`에는 공개 도메인·원격 주소·검증 메타 태그·공개 분석 식별자를 보관했습니다. 해당 정보는 비밀 API 키가 아니며 새 앱에서는 광고·분석 스크립트를 실행하지 않습니다. 원본 앱 전체는 백업 브랜치로 복구 가능합니다.

## 구현

- React + TypeScript + Vite 신규 프로젝트, 잠금 파일과 Node 버전 지정
- 한국어 관리자 대시보드: 실제 로컬 글감 개수, 상태별 현황, 명시적인 샘플 차트·키워드
- 글감 관리: CRUD, 검색, 필터, 목록·보드, 새로고침 후 유지, 오류 처리
- 키워드 분석 UI: 샘플 검색·필터·정렬, 상세 정보, 글감 저장
- 데이터 연결: 서비스별 연결 예정 상태, 로컬 저장 범위 안내
- 교체 가능한 저장소 계약과 다음 Phase용 분석·생성 계약
- 데스크톱·모바일 스타일, 키보드 접근 가능한 폼과 네이티브 다이얼로그
- 단위·통합 테스트, 브라우저 검증, 타입 검사, 정적 빌드, 배포 없는 CI

SRS 원문이 제공되지 않아 명시된 Phase 0 목록을 기준으로 구성했습니다. 추가 SRS와 일치 검증은 보류 사항입니다.

브라우저 테스트는 네 화면의 직접 주소 접근, 런타임 오류, 실제 화면 폭을 넘는 문서 가로 스크롤, 글감 추가·수정·새로고침 후 유지, Escape 닫기, 모바일 메뉴, 키워드 필터를 확인했습니다. 모바일 테스트 중 발견한 숨김 테이블 헤더의 가로 넘침은 스크롤 컨테이너에 위치 기준을 지정해 수정했습니다. 입력 폼은 좁은 화면에 맞는 열 너비와 16px 입력 글꼴을 적용했습니다.

데스크톱 대시보드·키워드 화면, 모바일 대시보드·데이터 연결 화면과 320px 입력창 캡처도 직접 확인했습니다. 캡처는 Git에서 제외되는 `test-results/`에 있습니다. 내장 브라우저 연결은 제공되지 않아 설치된 Google Chrome의 독립 테스트 세션으로 검증했습니다. 테스트 서버는 종료되었습니다.

타입·단위 테스트·빌드는 현재 실행 환경 Node.js 26.5.0에서 검증했습니다. CI는 `.nvmrc`의 Node.js 24를 사용하도록 구성했으며 원격 CI 자체는 실행하지 않았습니다.

새 구현은 `rebuild/phase0` 작업 트리에 남겨 두었습니다. 신규 구현 커밋이나 원격 push는 하지 않았으며 기존 코드는 이미 확보한 백업 브랜치로 보존됩니다.

## 배포와 범위

원격 push, PR 작성, 운영 배포, Cloudflare 설정 변경, 도메인 수정, 실제 수집·AI 호출은 하지 않았습니다. 로컬 테스트가 운영 데이터에 쓰지 않습니다. 기존 서비스는 기존 배포 상태로 남아 있습니다.

향후 빌드 기준은 `npm run build` / `dist`입니다. [Cloudflare 공식 설정 문서](https://developers.cloudflare.com/pages/configuration/build-configuration/)를 확인하여 준비했으며 원격 설정에는 적용하지 않았습니다. [Vite 공식 시작 문서](https://vite.dev/guide/)의 Node 요구사항도 확인했습니다.

Phase 0를 끝으로 작업을 종료하며 이후 기능이나 운영 전환을 자동으로 진행하지 않습니다.
