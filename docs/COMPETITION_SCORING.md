# 경쟁 분석 평가 기준 — 실험용 제안

작성일: 2026-10-19. 이 문서는 평가 설계이며 검증된 예측 모델이 아니다. Phase 1에서는 아래 점수 계산을 실행하지 않는다. 기존 DEMO 기회 점수는 가상 예시이며 사용자 자료에 복사하지 않는다.

## 평가 요소와 잠정 가중치

모든 가중치·등급·임계값은 **실험용이며 성과 검증 전**이다. 0~4점 등급을 사용한다면 높은 점수는 발행에 유리한 근거를 뜻하도록 일관되게 정의한다. 미확인은 0점이 아니라 결측값이다.

| 요소                    | 실험 가중치 | 필요한 근거와 판단 방향                                                                   |
| ----------------------- | ----------- | ----------------------------------------------------------------------------------------- |
| 검색 수요               | 20%         | 같은 시점의 PC·모바일 검색수, `<10`/누락 구분, 계절성 확인; 많을수록 무조건 유리하지 않음 |
| 상위 콘텐츠 최신성      | 10%         | API 결과 발행일과 사용자가 확인한 업데이트 필요성; 오래된 글도 유효할 수 있음             |
| 상위 콘텐츠 품질        | 20%         | 허용된 범위의 사람이 읽은 평가: 정확성·직접 경험·출처·구체성; 제목/요약만으로 판단 금지   |
| 검색 의도 일치도        | 20%         | 정보·비교·구매 등 의도와 실제 원고의 해결 가능성                                          |
| 대형 사이트 점유        | 10%         | 조사 표본의 도메인 분포와 수동 확인; API 순위는 통합검색 점유율이 아님                    |
| 신규 블로그 진입 가능성 | 15%         | 유사 규모 사례와 독자적 경험·좁은 주제의 빈틈; 총 문서 수만으로 추정 금지                 |
| 기존 발행 글과 중복     | 5%          | 내 발행 이력, 유사 검색 의도, 기존 글 보완 가능성                                         |

향후 실험 합산식: `Σ(요소 등급 / 4 × 가중치)` (100점). 필수 근거가 없으면 합산·순위화를 생략한다. 검색광고 `compIdx`는 광고 경쟁 지표이므로 블로그 경쟁 점수로 넣지 않는다. `검색량 / total` 같은 단순 비율을 진입 난이도로 간주하지 않는다.

## 네 가지 결과

| 결과        | 제안 기준                                                                                               |
| ----------- | ------------------------------------------------------------------------------------------------------- |
| 발행 추천   | 수요·의도·상위 콘텐츠 표본·차별화·중복 검토의 근거가 모두 있고 사람이 최종 승인한 경우                  |
| 롱테일 전환 | 수요 또는 의도는 있으나 주제가 너무 넓거나 기존 강한 콘텐츠와 차별화가 부족하고 구체화 근거가 있는 경우 |
| 보류        | 인증/자료/품질/시점/의도 근거 부족, 출처 간 충돌, 또는 재확인이 필요한 경우                             |
| 발행 제외   | 중복 통합이 적절하거나 주제 부적합·해결 불가능 등의 명시적 근거가 있는 경우; 검색수 0만으로 제외 금지   |

현재 `assessResearch()`는 모든 수동 자료에 **보류**와 부족한 근거 설명을 반환한다. 나머지 결과는 타입과 문서에 정의했으나 자동 판정하지 않는다. 인증된 검색수만 확보해도 콘텐츠 품질 근거가 없으면 자동으로 발행 추천하지 않는다.

## 검증 계획

별도 Phase에서 사용자가 허용한 표본을 고정하고 평가자·조회일·API 정렬 방식·선정 기준을 기록한다. 두 명 이상의 평가 일치도와 발행 후 관측 기간별 성과를 검토한다. 기존 글/계절성/블로그 규모 효과를 분리하고, 학습 표본과 검증 표본을 나눈다. 임계값은 실제 결과를 본 뒤 결정하며 점수만으로 순위 상승·수익을 보장하지 않는다. 가중치 변경 시 버전과 근거를 남긴다.

## Phase 2C 후보 선정과의 구분

Phase 2C의 후보 상태는 위 미래 경쟁 점수와 별개다. `src/domain/candidates.ts`의 rules-v1은 실측/입력 검색량과 규칙 추정을 구분하고, 주제·의도·사용자 지정 Reviewman 연결어·유사 표현 중복을 검토한다. 실험 가중치나 경쟁 점수는 계산하지 않는다. 연령 가중치도 없다. [구체적 규칙과 한계](PHASE2C_REPORT.md)를 참고한다. 기존 수동 분석의 `assessResearch()` 보류 판정은 유지하며 후보 우선순위와 혼동하지 않는다.
