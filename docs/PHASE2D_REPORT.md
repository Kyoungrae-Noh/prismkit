## 판단 기준

[경쟁 평가 기준](COMPETITION_SCORING.md)에 구현 순서와 필수 근거를 기록했다. 모든 평가는 초기 실험용이다. 결과 수가 적거나 검색량이 많다는 이유로 추천하지 않는다. 검색광고 경쟁도는 사용하지 않는다. 누락/오래된 자료는 추가 조사로 남기며, 캡처만으로 경쟁을 분석했다고 표시하지 않는다.

최종 상태는 발행 검토 추천 / 롱테일로 변경 / 추가 조사 필요 / 발행 보류 / 발행 제외다. 추천 계정은 세 계정 이력 확인과 실제 발행 완료 주제 이력·중복을 근거로 제안하며, 이력이 없거나 동률이면 미확정이다. 수익성·노출 확률·종합 점수를 생성하지 않는다.

## 저장과 제약

- 새 저장 키 `prismkit.publishing.v1`을 추가해 기존 글감·키워드·후보 스키마를 수정하지 않았다. 기존 데이터 변환 없이 호환된다. 손상/알 수 없는 버전은 자동 초기화하지 않는다.
- PNG/JPEG/WebP: 파일당 512 KiB, 후보당 3장, 전체 1.5 MiB, 2,000만 화소. 저장 시 4 MiB UTF-16 추정 예산 및 브라우저 실제 할당량을 검사한다. 실패 시 기존 데이터와 폼 입력을 유지한다.
- 브라우저별 로컬 데이터이며 자동 동기화가 없다. 후보 자체의 JSON 가져오기는 기존 Phase 2C와 마찬가지로 미구현이다. 다른 브라우저에서 현재 후보 ID가 없는 분석을 가져오면 원본은 보존되지만 후보 화면에 자동 연결되지 않는다. 원래 브라우저 및 후보 JSON을 함께 보관해야 한다.
- 동일 ID에 변경된 내용을 가져와 기존 자료를 덮어쓰는 기능은 제공하지 않는다. 현재 화면에서 수정하거나 중복 없는 새 ID를 사용한다.
- 검색 환경·품질은 사용자의 수동 관측이며 전체 네이버 경쟁 환경을 자동 검증한 자료가 아니다. 같은 주제와 유사 의도는 규칙 추정이므로 사용자 검토가 필요하다.
- API HUB, 크롤링, AI 판독/생성, 자동 발행, Reviewman 수정은 미구현(요청한 제외 범위).
