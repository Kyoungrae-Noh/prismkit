About Prism Kit

Prism Kit is a small collection of color tools built for designers and developers who need a quick answer — a HEX value, a palette, a gradient, a contrast ratio — without creating an account or waiting on a slow, ad-heavy page.

What we offer

  • Color Picker — get HEX, RGB, and HSL values from any color.
  • Palette Generator — build analogous, complementary, triadic, or shade palettes from one base color.
  • Gradient Generator — create a two-color CSS gradient and copy the code.
  • Contrast Checker — test a color pair against WCAG AA/AAA accessibility standards.
  • Image Color Extractor — pull a color palette out of any photo.
  • Color Name Finder — get a human-readable name for any HEX code.

How it works

Every tool on this site runs entirely in your browser using JavaScript. Nothing you type, pick, or upload — including images used in the color extractor — is sent to a server or stored anywhere. When you close the tab, everything is gone.

Who's behind this

Prism Kit is an independently run project. We built it because we found ourselves needing these exact tools often enough that a fast, no-friction version was worth making. If something's broken or missing, the contact page is the fastest way to reach us.
