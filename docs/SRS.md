# Prismkit SRS — Phase 1

작성·확인일: 2026-10-19. 대상: `/Users/kkr/website/prismkit.online`.

## 목적과 최종 워크플로

Prismkit은 글감 수집부터 키워드 검증, 콘텐츠 준비와 성과 관리를 지원하는 시스템이다. 기존 색상 도구와는 별개이며, 아래 전체 흐름은 최종 요구사항이다. Phase 1 완료를 전체 구현 완료로 해석하지 않는다.

1. 사용자가 여러 사이트에서 글감 캡처 수집
2. 캡처 이미지 업로드
3. AI가 글감·주제·핵심 키워드 추출
4. 글감별 시의성·검색 의도·수익화 가능성 평가
5. 네이버 자동완성·연관검색어 등을 통한 키워드 확장
6. 월간 PC·모바일 검색량 확인
7. 검색 결과 및 상위 블로그 경쟁 분석
8. 검색 수요·경쟁·차별화 가능성에 따른 발행 우선순위 결정
9. SEO·GEO·AEO 기반 원고 생성
10. 이미지 5장 및 네이버 발행 자료 준비
11. Reviewman 연결 및 UTM 관리
12. 발행 이력·성과 분석

## 이번 범위

5~8번에 필요한 데이터 기반만 구축한다. 공식 소스 조사, 공급자 인터페이스, 수동 입력과 출처 보존, 경쟁 평가 기준 설계가 대상이다. 인증 키가 없는 상태에서는 실시간 API 연결이나 경쟁 분석 완료를 주장하지 않는다. 자동완성·검색화면 연관검색어는 허용된 공식 자동 수집 경로를 확인할 때까지 수동 입력으로 대체한다.

## 데이터 의미

- `mode`는 자료 유입 방식(MANUAL / DEMO / API), `verification`은 검증 증거 수준이다. 수동 저장 성공이 API 검증 성공을 의미하지 않는다.
- 사용자 확인 날짜는 일 단위로 저장한다. 수집 시각을 알 수 없는 수동 자료의 `collectedAt`은 로컬 입력 저장 시각으로 정의하고 화면에도 저장 시각으로 표시한다.
- 기록 하나의 출처·날짜는 모든 입력값에 공통 적용된다. 다른 출처/시점의 값은 별도 기록으로 입력한다. 앞으로 API 필드별 provenance가 필요하면 모델을 확장한다.
- 검색광고 검색수는 최근 30일 기준이다. 데이터랩은 조회 범위 내 상대 지수이며 절대 검색량으로 환산하지 않는다.
- 블로그 API total은 해당 질의의 응답 수치, API 순서는 API 내부 순서다. 전체 문서 수·통합검색 실제 노출 순위와 동일시하지 않는다.
- 원문 본문이나 콘텐츠 품질 자료는 확보하지 않았다. 상위 콘텐츠 분석을 완료한 것처럼 표시하지 않는다.

## 비기능 및 제외 범위

React + TypeScript + Vite, 기존 로컬 저장과 UI를 유지한다. 320px·390px·1440px 화면에서 사용할 수 있어야 한다. 사용자 입력은 텍스트로 렌더링하며 HTML로 실행하지 않는다. 자격증명·원시 API 응답은 브라우저에 저장하지 않는다.

로그인/서버 저장/동기화는 미구현이다. 관리자용 운영 접근 제어는 향후 작업이며 현재는 로컬 프로토타입이다. 브라우저 자료 삭제 시 데이터가 사라진다. `.git`, 비밀 파일, 기존 배포 보존본, 다른 프로젝트를 수정·삭제하지 않는다.

원고·이미지 생성, 네이버 발행, Reviewman 운영 코드, 결제, 배포, DNS 변경, 원격 push, 비공식 검색 크롤링은 제외한다. Phase 2는 별도 지시 후 진행한다.
